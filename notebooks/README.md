# Notebooks

## `deep-dive.qmd`

A long-form treatment of what each method actually does, built up in the order
you need the pieces rather than the order the API lists them:

1. The re-identification problem — why an anonymised table is not anonymous
2. Column types, and the failure mode of the detection heuristic
3. Copulas, from Sklar's theorem to the distributional transform
4. A membership-inference attack on the output of step 3
5. Differential privacy, starting from randomized response
6. Private copulas and Analyze-Gauss
7. MST, and why a tree makes reconciliation exact
8. Diffusion, two noising processes, and ghost clipping
9. Evaluation metrics
10. How these methods break
11. Choosing an engine, measured

Four real datasets (Adult, German Credit, Wine Quality, Covertype) run through
it. Every figure is generated by the code shown above it.

## `guided-tour.qmd`

The earlier, shorter walkthrough. Superseded by the deep dive.

## Running them

```bash
julia --project=notebooks -e 'using Pkg; Pkg.instantiate()'
quarto render notebooks/deep-dive.qmd
```

Needs [Quarto](https://quarto.org) 1.5 or later for its native Julia engine.
This environment is separate from the package's own so that CairoMakie does not
enter the test or benchmark environments.

Datasets download on first run (about 60 MB, mostly Covertype) and cache under
`benchmark/data/`, shared with the benchmark suite.

### Render time

Budget around fifteen minutes. Almost all of it is the single
`DiffusionGenerator` trained in section 8; everything else runs in seconds.

Quarto's `cache` option does not help here. A `notebooks/.cache/` directory
*is* produced, but an unchanged re-render still executes every cell from the
first — verified by timing one. So there is no way to skip that fit short of
editing the epoch count down while drafting.
