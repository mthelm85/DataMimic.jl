Rasterize the logo

Renders logo-source.svg to a transparent PNG. Two variants come out of the one master:

  • Full — octopus and wordmark. This is docs/src/assets/logo-wordmark.png, floated in the README at 200 px where the wordmark is legible.
  • Mark only — the octopus, cropped to its own bounds with the wordmark dropped. This is docs/src/assets/logo.png, the docs navbar icon. The navbar renders it 32 px tall and already prints "DataMimic.jl" beside it, so the wordmark would be both illegible and redundant there.
  • Favicon — the mark again, centred in a square canvas, since the octopus is wider than it is tall and a favicon must be square. This is docs/src/assets/favicon.png.
Serve this page over HTTP rather than opening it from disk — browsers block both fetch and canvas export on file://. From the repository root:
python -m http.server 8000 then open http://localhost:8000/assets/rasterize_logo.html
